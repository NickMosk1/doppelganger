# Doppelganger - Цифровой двойник промышленной сети

## 📋 О проекте

Doppelganger - система для моделирования промышленных локальных сетей. Позволяет создавать цифровые двойники сетевой инфраструктуры и симулировать воздействие различных факторов:

- 🌡️ **Температура** - перегрев оборудования
- ⚡ **Электромагнитные помехи (EMI)** - влияние на кабели и устройства
- 📳 **Вибрация** - механическое воздействие
- 🏭 **Запылённость** - влияние на охлаждение и контакты

### Технологический стек

| Компонент | Технология |

| Frontend | React 18, TypeScript, Vite |
| База данных | PostgreSQL 16 |
